假设一个 1000 × 1000 的矩阵只有 100 个非零元素。如果逐项保存，我们仍然要为一百万个位置分配空间。

## 把位置也存下来

坐标格式（COO）的想法很直接：为每一个非零元素记录行号、列号和值。

```python
# A[0, 2] = 4, A[3, 1] = 7
rows   = [0, 3]
cols   = [2, 1]
values = [4, 7]
```

这时，存储量主要随非零元素的数量增长。当然，索引本身也有开销；矩阵不够稀疏时，这个办法未必划算。

## 结构带来的线索

对角、分块、带状——非零元素的位置往往暴露了问题的结构。它们可能对应邻接关系、局部相互作用，或某个离散算子的作用范围。

画出这些位置，有时比盯着具体数值更容易发现规律。

## 一个小结

稀疏不仅意味着“少”。它也意味着，我们有机会明确说出：哪些关系存在，哪些关系可以忽略。
